# Code of Conduct

The ACES Innovation Hub is a student community for learning, collaboration, and responsible innovation. Everyone participating in this repository or its associated activities is expected to:

- Treat others with respect and communicate constructively.
- Welcome people with different backgrounds, identities, and levels of experience.
- Give feedback about ideas and work without personal attacks or harassment.
- Respect privacy, consent, and the ownership of others' work.
- Follow applicable university rules and safety guidance.

Harassment, discrimination, intimidation, and knowingly harmful or disruptive behavior are not acceptable. If a concern arises, report it privately to an appropriate ACES or Hub representative through an official channel. Do not publish sensitive details in a public issue.

This code applies to repository contributions and Hub activities connected to this community.
