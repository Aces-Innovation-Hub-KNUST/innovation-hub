# Projects

This directory is for projects that have been approved to enter the Hub's project pipeline or incubation process. Do not add invented or sample projects as if they were real.

## Adding a project

1. Confirm that the project is approved for inclusion under the Hub's current process.
2. Create a clearly named directory using an agreed project name or neutral identifier.
3. Start its `README.md` from the [project idea template](../templates/project-idea.md), then adapt it into a concise project overview.
4. Record the current stage, team information appropriate for sharing, next milestone, blockers, and support needs.
5. Keep decisions, check-ins, and milestones current, using the relevant templates.
6. Do not publish unnecessary personal information, credentials, or confidential funding details.

## Suggested project README sections

- Summary and problem
- Target users
- Proposed solution and technical approach
- Team (only information appropriate for this repository)
- Current pipeline stage
- Expected prototype or current demo
- Milestones and check-in notes
- Risks, blockers, and support needs
- Next step

See the [project pipeline guide](../docs/hub/project-pipeline.md). Funding is not guaranteed; record opportunities and outcomes only when confirmed.
