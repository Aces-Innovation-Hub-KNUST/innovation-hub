# Hub overview

The ACES Innovation Hub supports student-led innovation and project development in association with the Association of Computer Engineering Students (ACES), KNUST. Its project pipeline is **Idea → Prototype → Funding**, with screening, incubation, mentorship, milestones, check-ins, and opportunities to showcase work along the way.

The Hub also plans software development activities, including skill sprints and a Software Hackathon. Activities described in the 2026/2027 plan should be treated as planned until organizers confirm their status.

## Working principles

- Start from a real problem and identify the people affected.
- Use screening to assess problem fit, feasibility, team, and next step.
- Help teams make progress through mentorship and manageable milestones.
- Explore funding only when appropriate; funding is not guaranteed.
- Document decisions and project status so future teams can continue the work.
- Treat this repository and its documentation as organizational assets.

See [governance](governance.md), [the project pipeline](project-pipeline.md), and [handover expectations](handover.md) for operational guidance.
