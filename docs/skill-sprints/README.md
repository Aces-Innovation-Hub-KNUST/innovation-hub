# Software skill sprints

Skill sprints are planned opportunities to build practical skills relevant to student projects. The 2026/2027 plan identifies these areas:

- Git/Linux
- Microcontrollers
- Web/APIs
- Embedded C

This directory provides a flexible place to document each sprint. The plan does not specify instructors, exact dates, venues, or detailed course content; add those details only after organizers confirm them.

## Suggested documentation for a confirmed sprint

Copy this outline into a new, clearly named document when a sprint is approved:

```markdown
# [Sprint title]

- Status: Planned / Confirmed / Completed
- Date(s):
- Location or format:
- Organizer or responsible committee:
- Intended participants:
- Learning goals:
- Prerequisites, if any:
- Materials or setup:
- Schedule or activities:
- Follow-up resources:
- Notes and improvements for next time:
```

Keep the record accessible to future organizers. Do not add personal contact details, credentials, or unconfirmed information.
